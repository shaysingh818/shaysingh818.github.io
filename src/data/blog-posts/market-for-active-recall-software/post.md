## Problem

Recently I've been studying anatomy and various other subjects related to healthcare. A common theme I noticed is the ability of active recall and being able to train your brain to remember a lot of information. Reading textbooks and literature isn't enough on it's own to truly be able to recall and apply information like muscle memory. 

It got me thinking about the current state of software in the market that helps with active recall of information, some familiar software products like quizlet, anki or brainscape target this type of problem. While these products solve the problem of making it easier to store information and test with active recall, it seems like you have to weigh the tradeoffs of using something that will cost money vs something that will not have an intuitive user interface that increases the barrier of entry. 

## The Hypothesis

A product could be made that takes all the best components of the paid & free versions of active recall memorization software and be made fully available to any educator, healthcare professional, student etc. without requiring paywalls and still have a good user interface with low barrier to entry. 

## Evaluation Of Current Market Competition

### Quizlet

Quizlet was a godsend when being in school, one of it's most notable features is how it trained you to associate information it exposed you to, then increased the difficulty of recall by going to "open ended" or "multiple choice" questions. Quizlet has a lot of great features however, the decks and management of data is by a central authority, this can problematic if academic institutions want to keep their material confidential so other students can use confidential decks. On top of that, quizlet shot itself in the foot by creating paywalls and infesting their product with ads. 

### Anki

Anki is exactly what I would want in spirit, however is not what I expected in practice when using the desktop app for the first time. I honestly thought this product had beat me to it until I used their user interface. The user interface itself is just hard to use and I couldn't understand how med students, educator i.e low barrier to entry users could use it. Besides the UI, the techniques for recall are pretty limited, it's mainly a simple flashcard setup with front & back questions, there isn't an option to create matching/multiple choice questions

### RemNote

RemNote is a strong solution, the combination of taking notes and converting them into flashcards is a good feature, the only edge to compete against RemNote is to offer the same features but offer a local first/decentralized model with the same capabilities and add more recall techniques besides flipping flashcards back & forth. 

## Next Steps 

Over the next few months, I'm going to attempt to build a prototype and see if it can target a niche in this market. Specifically a prototype for a flashcard app will be built that will be supported on desktop & mobile, it will be local first, allow local networked study sessions, include richer recall techniques besides "front & back" flashcards. The goal with this project will be to see if we can make something that is the best of all existing products without a paywall and fully decentralized.
